# xiaoai-dsh 技能体系

音箱的「大脑」有两层能力：**快通道工具**（OpenAI function calling，秒级）
与**深通道技能**（SKILL.md，任务匹配时注入深通道执行）。两者互补：

- **快通道工具**：确定性、结构化，适合「查状态/开关设备/点歌」这类高频指令。
- **深通道技能**：流程性、可叙述，适合「多步查询/分析/操作」这类复杂任务；
  技能教会深通道"按什么流程做"，是自我进化的主要载体之一。

## 1. 技能库机制

- **库目录**：仓库 `skills/speaker-skills/<技能名>/SKILL.md`（标准
  frontmatter：name + description）。
- **注入方式**：桥通过 `SKILLS_DIR` 常量读取整个技能库，深通道任务启动时
  把技能库文本注入提示词（「音箱专用技能库，当前任务若与某个技能匹配，
  按其步骤执行」）。控制注入长度：最多 5 个技能、每个截 800 字。
- **沉淀方式**：深通道解决复杂问题后，在回答末尾附
  `【技能】名称/何时使用/步骤…【技能结束】` 块，桥解析后自动写入
  skills/speaker-skills/<名>/SKILL.md（kebab-case 命名），下次同类任务
  直接按既有流程走。这是「流程复用」式自我进化。
- **只归音箱用**：技能库独立存放，不污染用户主 DSH 的技能库。
- 配套机制：`【工具】…【工具结束】` 块沉淀声明式工具（evolved-tools.json，
  http 仅限本机 HA、shell 仅限只读），注册进快通道工具列表。

## 2. 技能清单

### 2.1 web-audio-play — 网络音频在线播放（通用链路）

- **触发场景**：用户让音箱播放网络上的音频资源——点歌、播放某角色/某节目
  的演唱或声音、播放某个网页视频的声音等。
- **核心链路**：「用浏览器在网络平台找音频 → 音箱在线播放」，不绑定具体
  平台或具体内容。
- **实现**：执行 `web-audio-play.py`（仓库 bridge/ 目录），平台注册表架构：
  - **bilibili 适配器**：ego-browser 登录态 cookie + wbi 签名搜索 + playurl
    音频流直链；
  - **generic 浏览器捕获兜底**：打开页面抓 `<video>/<audio>` 与网络媒体流
    直链，不依赖任何平台 API 和登录态（任意网页都可用）；
  - **防盗链 relay**：播前探测音频流 URL 能否裸拉，不能（403/400）就自动起
    Mac 本机流式转发（4378 端口，带 Referer/UA，零落盘零转码），音箱改拉
    本机转发地址；转发进程 30 分钟无请求自动退出。
- **用法**：`web-audio-play.py "关键词" [--list|--index N|--platform x|--bvid|--url|--stop]`。
  用户说「不是这首/换一个」→ 先 --list 列候选选序号，再 --index N 播；
  已知 BV 号 → --bvid；已知页面 URL → --url；「停/别放了」→ --stop。
- **要点**：每次播放都现解析流 URL（平台流有时效/防盗链参数，绝不缓存复用）；
  播放是抢占式的（新音频顶掉旧音频）；音箱 miplayer 直接在线拉流，不需要
  下载和转码；ego lite 未运行会自动拉起，有登录态自动用登录态。
- **扩展**：PLATFORM_ADAPTERS 注册表加适配器即可；或直接 --url + generic。

### 2.2 netease-music — 网易云音乐（音箱版）

- **触发场景**：用户要点歌、放每日推荐、放红心歌单、放我的歌单、查歌词；
  或快通道 netease_music_play 等工具失败降级到深通道时。
- **CLI**：`netease-music`（node 脚本，自备网易云账号 cookie，VIP 可拿无损
  音质；`--status` 可查风控状态）。
- **命令**：search / daily / liked / playlists / playlist / url(--level
  lossless) / lyric / whoami。
- **播放流程**：搜索或列表选歌 → url 拿直链 → POST 127.0.0.1:4398/play_url
  → 把「歌名 - 歌手」写进最终回答（桥会润色播报）。URL 时效约 20 分钟，
  过期重取。
- **反封号红线（违反会封号，必须遵守）**：
  - CLI 内置 ≥5s 请求间隔（5-9s 抖动），禁止跳过等待；
  - 一次任务 ≤5-8 次调用；禁止并发跑多个 CLI 进程；禁止 for 循环批量拉；
  - `--status` risk_level≥2 → 当天不再调用，改用 web-audio-play 技能。
- **坑**：artists 字段是字符串（用 / 分隔）不是数组；歌词 LRC 每行带
  [mm:ss.xx] 时间戳要剥掉再念；搜索可能混入翻唱，优先选正版/大牌结果；
  无版权歌 url 为 null（试听只有 60s 片段，别播）；歌单列表字段是 count
  不是 trackCount。

### 2.3 dingtalk-query — 钉钉数据查询

- **触发场景**：用户问任何钉钉相关的事——「钉钉上有没有人找过我」「XX
  给我发消息了吗」「查一下钉钉邮件」「看看今天的日程」「找一下 XX 同事」等。
- **CLI**：dws（钉钉官方 Workspace CLI），账号由部署者自行登录（dws auth
  login --device 扫码），直接查，不要问用户要账号/密码。**dws 用绝对路径**
  （launchd 常驻进程 PATH 不含 ~/.local/bin 时要用全路径）。
- **常用查询**：
  - 有没有人找过我 / 最近消息：`dws chat +conversation-list` /
    `+chat-messages --open-conversation-id <cid>`，判断「别人找过我」要看
    sender 不是自己；
  - 查邮件：`dws mail +list`；查日程：`dws calendar`；
  - 找同事/查通讯录：`dws contact user search` / `dws aisearch person`；
  - 查知识库/文档：`dws aisearch enterprise`。
- **播报要求**：结果整理成口语短句（谁、什么时候、说了什么），别念全文；
  没消息就如实说「最近没有人找您」；时间戳转成「8月21日 上午11点」口语。
- **注意事项**：输出用 --format json 按真实字段解析，不猜字段名；只读查询
  随便查，写操作（发消息/发邮件）先跟用户确认；登录态失效如实告知需要重新
  扫码授权，不要反复重试。查询命令不确定时先跑 `dws <产品> --help` 或看
  钉钉官方技能库。
- **归属**：音箱侧深通道用本技能；Mac 主 DSH 会话直接用钉钉官方技能
  dingtalk-*。

### 2.4 home-network-plan — 家庭网络规划

- **触发场景**：用户需要梳理家庭网络拓扑或制定网络优化方案时。
- **步骤**：实体搜索找网络/路由/无线相关集成 → 拉取系统设备概览，盘点全屋
  设备构成（摄像机、音箱、开关、传感器等）与分布区域 → 结合设备规模与类型，
  撰写拓扑梳理与优化方案文档（有线优先、双频分离、智能设备隔离、限速与
  验收标准）。

### 2.5 power-hungry-device-audit — 高耗电设备审计

- **触发场景**：用户询问家里哪些设备费电、需要节电建议时。
- **步骤**：实体搜索 power/耗电/插座/计量，定位计量插座、电功率、耗电量
  传感器 → 读取电功率当前值与近一周历史，判断负载水平与使用规律 → 列出
  当前开启的高功耗设备（摄像机、风扇、除湿机等），结合功能开关状态给出
  节电建议 → 若计量点不足，建议补充计量插座后再按月输出分设备用电报告。

### 2.6 recent-file-changes — 最近文件变动分析

- **触发场景**：分析电脑上最近 N 天修改过的文件并按时间排序时。
- **步骤**：限定常用目录（工作/桌面/文稿/下载）并排除工程缓存
  （node_modules/.git/__pycache__）查找近 7 天修改的文件 → stat 取修改
  时间/大小后按时间倒序排列 → 按二级目录分组统计，识别改动热点（如日志/
  数据库类过程文件），给出清理建议。

### 2.7 mac-temp-cleanup — Mac 临时文件清理

- **触发场景**：用户要求清理电脑临时文件或缓存、释放磁盘空间时。
- **步骤**：先查看各临时目录占用（~/Library/Caches /tmp /var/tmp）→ 删除
  超过 7 天未使用的缓存文件并清空目录 → 用 df/du 验证释放空间与清理结果。

## 3. 技能与工具的分工示例

| 用户问 | 走哪条路 | 为什么 |
|--------|---------|--------|
| 放首歌 | 快通道 netease_music_play（工具） | 确定性、秒级、正版快链 |
| 网易云搜不到/无版权 | 降级 web_audio_play 工具 → 深通道 | 工具降级链 |
| 钉钉上有人找我吗 | 深通道 dingtalk-query（技能） | 多步 CLI 查询 + 口语整理 |
| 家里哪些设备费电 | 深通道 power-hungry-device-audit（技能） | 多实体对比分析 |
| 清理一下电脑垃圾 | 深通道 mac-temp-cleanup（技能） | 多步 shell + 验证 |
| 最近改了哪些文件 | 深通道 recent-file-changes（技能） | 文件系统遍历分析 |
| 家庭网络怎么优化 | 深通道 home-network-plan（技能） | 盘点 + 方案文档 |

技能由深通道在任务匹配时注入执行，与快通道工具互补：能固化成确定性调用的
沉淀为工具（秒级复用），需要流程指导的沉淀为技能（深通道复用）。
